# Castaways · 표류단

치지직 채팅으로 참여하는 무인도 생존 웹게임입니다. 장소를 선택하고 무작위 사건을 겪으며 최대 8라운드 동안 생존을 겨룹니다.

## 로컬 실행

Node.js 24 이상이 필요합니다. 실행에 필요한 브라우저 클라이언트는 포함되어 있어 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
node scripts/build.mjs
node scripts/preview.mjs
```

`http://127.0.0.1:8765`에서 가상 시청자 체험 모드를 사용할 수 있습니다.

```sh
node api-check.mjs
node stage-check.cjs
node chzzk-client-check.cjs
```

치지직 실제 연동에는 개발자 앱과 서버 환경 설정이 필요합니다. 배포 전 [보안 및 인증 경계](SECURITY.md)를 확인하세요. 개인별 사이트 ID·API 키·도메인·기존 배포 기록은 이 공개 저장소에 포함하지 않습니다. Sites 배포 시 `.openai/hosting.example.json`을 참고하여 로컬 `.openai/hosting.json`을 만들며, 실제 설정 파일은 커밋하지 않습니다.

치지직 채팅 참여형 무인도 생존게임. 게임 화면은 `public/`에 있고, 인증·채팅 구독 API는 `worker/api.mjs`에 있습니다. `npm run build` 후 `npm run preview`로 로컬 서버를 실행합니다. 배포된 게임의 **치지직 연결** 버튼에서 등록 안내와 연결 상태를 확인할 수 있습니다. [치지직 설정 안내](CHZZK-SETUP.md).

16명(사용자 + 가상 참가자), 8라운드, 장소별 위험 예고, 공동 무작위 사건, 체력·보물, 탈락 후 보호 부적 투표, 최종 순위를 구현했습니다. 키보드 1/2/3 또는 채팅 명령으로 선택합니다. `!참가 닉네임`은 시작 전에 가상 참가자를 추가합니다.

2026-10-18: 스크롤 없는 방송용 화면으로 변경했습니다. 장소 선택 20초 → 숲·해변·동굴 사건을 각각 3초씩 순차 공개 → 생존 결과 7초 → 다음 라운드로 자동 진행됩니다. 버튼으로 장면을 넘기거나 상단에서 일시정지할 수 있습니다. 도움말·지난 기록을 열면 진행이 멈추고 닫을 때 이전 정지 상태로 복구합니다. 명단은 8명씩 6초 간격으로 교대합니다. 좁은 화면에서는 보조 명단·가상 채팅 패널을 숨기고 지도·장소 선택·생존 인원·자기 체력·사건 결과를 유지합니다.

대기·선택 화면에는 파도·구름·해안선·나뭇잎·배·갈매기의 환경 애니메이션과 캐릭터별 다른 박자의 작은 움직임을 추가했습니다. 캐릭터 요소를 유지해 장소 변경 시 이동이 부드럽게 이어집니다. 일시정지 시 환경·캐릭터 애니메이션도 멈춥니다. 운영체제의 움직임 줄이기 설정을 따릅니다.

검증: `npm test` (게임 흐름·순위·실제 채팅 명령 처리·OAuth 상태 검증·암호화 쿠키·사용자 분리·토큰 갱신·세션 구독). 브라우저에서 1280×720, 1920×1080, 390×844에서 문서 스크롤 없이 화면에 들어오는지 확인했습니다. 실제 개발자 앱 등록 전이므로 실계정 로그인·실방송 채팅은 미검증입니다.

API 비밀키는 서버 환경에 두고, 토큰은 암호화된 HttpOnly 쿠키로 관리합니다. 시청자 ID는 공식 채팅 이벤트의 senderChannelId를 사용합니다. 채팅 수신 모드에서는 가상 참가자를 제외하며 연결 단절 시 진행 중인 게임을 일시정지합니다. 현재 게임 상태는 페이지를 새로 열면 초기화됩니다.
