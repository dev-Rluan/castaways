치지직 방송 연결

연결 상태를 확인하고 있습니다…

게임 운영자가 처음 한 번 개발자 앱을 등록합니다. 방송인마다 키를 발급할 필요는 없습니다.

  1. 치지직 개발자센터에서 애플리케이션을 만드세요. 이름 예: 표류단.
  2. API 권한은 유저 정보 조회 · 채팅 메시지 조회 두 가지만 선택하세요. 후원·구독·채팅 전송·방송 관리 권한은 현재 필요하지 않습니다.
  3. 로그인 리디렉션 URL에 아래 주소를 그대로 등록하세요.
  4. 발급한 Client ID와 Client Secret을 이 사이트의 서버 환경 설정에 등록하세요. 설정 이름은 CHZZK_CLIENT_ID, CHZZK_CLIENT_SECRET이며, 비밀키는 비밀 값으로 저장하세요.

비밀키를 채팅이나 게임 입력창에 보내지 마세요. 설정 후 사이트에 적용하면 연결 버튼이 활성화됩니다.
